# VisionAnnotator AI 🚀

An AI-powered Video Annotation Platform built with Python, FastAPI, YOLOv8, OpenCV, ByteTrack, and React.

---

# 🚀 Project Goal

VisionAnnotator AI is designed to build a complete AI-assisted video annotation platform where users can:

* Upload videos
* Automatically detect objects using AI
* Manually edit annotations
* Add labels, attributes, and captions
* Export annotated videos
* Generate AI training datasets

The platform combines AI automation with human annotation workflows to create high-quality computer vision datasets.
