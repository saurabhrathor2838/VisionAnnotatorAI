# VisionAnnotator AI

An AI-powered Video Annotation Platform built with Python, FastAPI, YOLOv8, OpenCV, ByteTrack, and React.

---

## 🚀 Project Goal

VisionAnnotator AI is designed to simplify video annotation by combining AI-powered object detection, object tracking, and manual annotation tools into a single platform.

---

## 🛠 Tech Stack

### Backend
- Python
- FastAPI
- OpenCV
- YOLOv8
- ByteTrack

### Frontend (Planned)
